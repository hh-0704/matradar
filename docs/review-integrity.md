# 리뷰 신뢰 구조

맛레이더는 "광고·체험단 리뷰에 속지 않는 맛집 판단"을 내세우는 서비스입니다. 그래서 리뷰 신뢰 체계의 **구체적인 탐지 방식은 공개하지 않습니다**.
탐지 기준이 알려지면 그 순간부터 기준을 피해 가는 방법을 알려 주는 셈이 되기 때문입니다.
이 문서는 체계가 **어떤 구조로 돌아가고, 왜 그렇게 설계했는지**만 설명합니다.

## 전체 흐름

```
            [ 점수기 · 비공개 ] ──▶ 검토 큐 ──▶ 운영자 판단 ──▶ 숨김·정지 또는 오탐 처리
                                                    ↑
                                             자동 제재 없음

가게 평점 = 작성자 신뢰도를 반영한 가중 평균 (한 사람은 가게당 최신 1건만)
```

- **리뷰 작성과 탐지는 분리돼 있습니다.** 탐지가 느리거나 실패해도 사용자의 리뷰 작성은 영향을 받지 않습니다.
- **점수기는 별도 모듈이고, 이 레포에 없습니다.** 점수기가 무엇을 보고, 언제 돌고, 어떻게 계산하는지는 비공개입니다.

## 설계 개념

### 점수는 판정이 아니라 검토 우선순위다

점수기가 내놓는 것은 "이건 어뷰징이다"라는 판정이 아니라 **"사람이 먼저 봐야 할 것"의 순서**입니다.
최종 판단은 운영자가 하고, 운영자는 오탐으로 판정해 되돌릴 수도 있습니다.

### 오탐 비용은 비대칭이다

정상 사용자를 어뷰저로 잘못 제재하는 비용은 어뷰저 한 명을 놓치는 비용보다 큽니다.
잘못 제재당한 사용자는 이유도 모른 채 떠나고, 리뷰 서비스에서 그건 가장 비싼 손실입니다.
그래서 **자동 제재를 두지 않습니다.**

### 탐지와 조치를 분리한다

"얼마나 의심스러운가"(탐지)와 "무엇을 할 것인가"(숨김·정지)는 다른 책임입니다.
조치는 운영자의 명시적인 행동으로만 일어나고, 모든 조치에는 되돌리는 길(복구·정지 해제)이 있습니다.

### 평점은 삭제가 아니라 가중으로 희석한다

가게 평점은 리뷰의 단순 평균이 아니라 **작성자 신뢰도를 반영한 가중 평균**입니다.
의심스러운 리뷰를 지우는 대신 그 리뷰가 평점을 움직이는 힘을 줄입니다. 판단이 틀렸을 때의 피해가 삭제보다 작습니다.
가중치를 어떻게 정하는지는 공개하지 않습니다.

## 화면에서 보이는 장치

사용자에게 그대로 보이는 규칙들입니다. 탐지가 아니라 **입력 단계에서 왜곡을 줄이는** 장치입니다.

| 장치 | 내용 |
|---|---|
| 별점 3점 시작 | 리뷰 작성 화면은 3점이 선택된 채로 열리고, 4~5점을 고르면 즉시 경고가 뜹니다 |
| 한 사람 = 한 표 | 같은 사람이 같은 가게에 여러 번 써도 평점에는 최신 리뷰 1건만 들어갑니다 |
| 같은 가게 24시간 1회 | 재방문 리뷰는 막지 않지만, 같은 가게에는 24시간에 한 번만 등록됩니다 |
| 게스트는 읽기 전용 | 가입 없이 둘러보는 계정은 쓰기를 할 수 없습니다. 제재해도 다시 만들면 되는 계정의 쓰기를 받으면 신뢰 구조의 전제가 무너집니다 |
| 광고·체험단 제보 | 사용자가 제보하고 운영자가 확정한 가게에만 "광고 의심" 안내가 붙습니다. 확정 전에는 표시하지 않고, 문구도 단정하지 않습니다 |

## 공개하지 않는 것

- 점수기가 보는 것
- 계산 방식과 기준값, 가중치
- 실행 시점과 조건
- 관련 클래스·설정 이름
